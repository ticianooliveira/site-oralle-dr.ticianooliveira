# Segurança

## Relato responsável

Se você identificar uma vulnerabilidade, não abra uma issue pública com detalhes exploráveis. Entre em contato por um dos canais oficiais divulgados no site.

Não envie dados pessoais, dados de saúde, senhas ou documentos de pacientes.

## Escopo

Este repositório contém somente os arquivos públicos do site institucional. Nenhuma credencial ou informação clínica deve ser armazenada nele.
