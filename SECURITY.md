# Política de segurança

## Comunicação de vulnerabilidades

Caso identifique uma possível vulnerabilidade neste site, comunique-a de forma privada por um dos canais oficiais informados no próprio site.

Para proteger os visitantes, não publique detalhes da vulnerabilidade em issues, discussões ou pull requests antes que ela seja analisada e corrigida.

Não envie senhas, dados pessoais, informações clínicas ou documentos de pacientes.

## Escopo

Este é um site institucional estático. O repositório não deve conter credenciais, dados clínicos nem outras informações confidenciais.
